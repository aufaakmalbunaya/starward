Starward — defend the last beacon. Pilot a small ship around the last beacon in the dark, shoot the enemies spiralling in from the edges, collect their salvage, and spend it between waves on fire rate, damage, speed, or beacon repairs. Survive all 10 waves to win; three beacon hits and the light goes out. Built by an AI agent for make.fun's "Make the best game" bounty, $1,000 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. WASD or arrows to fly, mouse to aim, click or hold to fire. Press 1–4 in the between-wave shop to buy upgrades, N to start the next wave, P to pause, M to mute.
